LIMPIADOR DE METADATOS (Windows)
================================

PASOS
-----
1) Ejecuta "eliminar_metadata.exe".
2) Selecciona una imagen o una carpeta.
3) Pulsa "Limpiar metadatos".

DONDE SE GUARDAN
----------------
- Las imágenes limpias se guardan en una carpeta junto al ejecutable:
  "imagenes_limpias"
- El programa NO modifica los archivos originales.

NOTA
----
Si te sale un error de ExifTool, pide una versión del ejecutable que ya incluya ExifTool.
